# 100 Days of C Programming

This repository contains my solutions for the **100 Days of Code - C Programming Daily Challenge**.

## Current Progress

**Day 01 to Day 35 completed - Q1 to Q70.**

Each day has two C programming questions. Every solution keeps the original question statement as a comment at the top and uses beginner-friendly C programming concepts.

## Topics Covered So Far

- Basic input and output
- Arithmetic operations
- Conditional statements (`if`, `if-else`, `switch`)
- Loops
- Number programs
- Nested loops and patterns
- One-dimensional arrays
- Linear and binary search

## How to Run a Program

Compile with GCC:

```bash
gcc Q01_Sum_of_Two_Numbers.c -o Q01
./Q01
```

On Windows:

```bash
gcc Q01_Sum_of_Two_Numbers.c -o Q01.exe
Q01.exe
```
